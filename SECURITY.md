# Security Policy

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/HeiGeAi/feishu-pet/security/advisories/new)
and include the affected version, reproduction steps, impact, and proposed
mitigation when available.

Never attach real Feishu credentials, `open_id`, `chat_id`, message history, or
local configuration. Use redacted test data and revoke any credential exposed
by mistake.
